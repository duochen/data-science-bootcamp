# UCI Air Quality Dataset Documentation

## Project Use

This dataset will be used for the project **Predicting Urban Air Pollution Using Sensor Environmental and Temporal Features**. The primary target is hourly nitrogen dioxide concentration, `NO2(GT)`. The main experiment compares sensor-only features with sensor plus environmental features and then with sensor, environmental, and engineered temporal features.

## Collection Description

UCI describes the data as hourly averaged measurements from an air-quality chemical multisensor device deployed at road level in a polluted area of an Italian city. The device included five metal oxide chemical sensors. Certified colocated analyzers supplied reference measurements for several pollutants. UCI also warns that the dataset contains cross-sensitivity, concept drift, sensor drift, and missing values.

## File Parsing Requirements

The CSV is not a standard comma-delimited U.S.-formatted file.

| File issue | Required Pandas setting or action |
|---|---|
| Semicolon-delimited columns | `sep=";"` |
| Decimal comma | `decimal=","` |
| Empty trailing rows | `dropna(axis=0, how="all")` |
| Empty trailing columns | `dropna(axis=1, how="all")` |
| Missing numeric measurements coded as `-200` | Replace `-200` with `numpy.nan` |
| Separate date and time fields | Parse with `%d/%m/%Y %H.%M.%S` |

Recommended loading code:

```python
from pathlib import Path
import numpy as np
import pandas as pd

data_path = Path("data/raw/AirQualityUCI.csv")

df = pd.read_csv(data_path, sep=";", decimal=",")
df = df.dropna(axis=0, how="all").dropna(axis=1, how="all")

df["datetime"] = pd.to_datetime(
    df["Date"] + " " + df["Time"],
    format="%d/%m/%Y %H.%M.%S",
    errors="raise",
)

numeric_columns = df.select_dtypes(include="number").columns
df[numeric_columns] = df[numeric_columns].replace(-200, np.nan)
df = df.sort_values("datetime").reset_index(drop=True)
```

## Engineered Variable Dictionary

These variables are created from `datetime` and are not present in the source CSV.

| Variable | Definition | Planned role |
|---|---|---|
| `hour` | Integer from 0 through 23 | EDA and source for cyclical encoding |
| `day_of_week` | Monday = 0 through Sunday = 6 | EDA and source for cyclical encoding |
| `day_name` | Name of weekday | EDA labels only |
| `month` | Integer from 1 through 12 | EDA and source for cyclical encoding |
| `weekend` | 1 for Saturday or Sunday; otherwise 0 | Feature Set C |
| `hour_sin` | `sin(2 * pi * hour / 24)` | Feature Set C |
| `hour_cos` | `cos(2 * pi * hour / 24)` | Feature Set C |
| `day_of_week_sin` | `sin(2 * pi * day_of_week / 7)` | Feature Set C |
| `day_of_week_cos` | `cos(2 * pi * day_of_week / 7)` | Feature Set C |
| `month_sin` | `sin(2 * pi * month / 12)` | Feature Set C |
| `month_cos` | `cos(2 * pi * month / 12)` | Feature Set C |

Cyclical encoding is used because values at the ends of a cycle are close to one another. For example, hour 23 is close to hour 0.

## Missing-Value Treatment

### Target

Rows with missing `NO2(GT)` will be excluded from regression because the target value is unknown. This leaves 7,715 target-valid rows in the checked CSV.

### Predictor Features

Missing predictor values will be handled with `SimpleImputer(strategy="median")` inside each scikit-learn `Pipeline`. The imputer must be fitted on training data only. Filling missing values before the train-validation-test split would allow later data to influence training preprocessing.

### Missingness Analysis

The project will also inspect whether missing values occur in contiguous time periods and whether several sensor and environmental columns are missing at the same timestamps. This matters because missingness may reflect device downtime rather than random missing records.

## Duplicate and Time-Gap Checks

## Data Leakage Controls

The following rules apply to the primary experiment:

1. `NO2(GT)` cannot appear in the predictors.
2. `CO(GT)`, `NMHC(GT)`, `C6H6(GT)`, and `NOx(GT)` cannot appear in the primary predictors.
3. Predictor imputation must be fitted through a pipeline on training data.
4. The primary split must preserve time order.
5. The final test period must not be used to choose features, model type, or model settings.
6. Quantile thresholds used for peak analysis must be calculated from training data.

## Data Quality Risks

| Risk | Possible effect | Planned response |
|---|---|---|
| `-200` is not converted | Invalid low values distort statistics and models | Replace before any numeric analysis |
| Blank trailing rows and columns remain | Loaded dimensions conflict with usable data | Remove only entirely empty rows and columns |
| Sensor drift | Relationships learned early may weaken later | Use a chronological test period and plot errors over time |
| Cross-sensitivity | One sensor may respond to several gases | Avoid treating nominal sensor labels as perfectly selective measurements |
| Nonrandom missingness | Device downtime may create biased valid periods | Visualize missingness over time and discuss it |
| Reference-analyzer leakage | Scores may look unrealistically strong | Exclude other `GT` pollutants from primary predictors |
| Pollution peaks are rare | Overall metrics may hide poor peak prediction | Evaluate error across target ranges and inspect the largest errors |

## Bias and Generalizability

- The data come from one device deployment in one Italian city.
- The measurements are historical and may not represent current sensors, traffic, fuels, regulations, climate, or urban conditions.
- The dataset does not support conclusions about all cities or populations.
- The dataset is observational. Relationships with time or humidity do not prove causation.
- The monitored location was described as significantly polluted and at road level, which may not represent other parts of the same city.
- Model performance on a later segment of this dataset does not prove performance on a new city or modern monitoring network.

## Ethical and Responsible Use

The model is an educational research model. It must not be used to issue public-health warnings, make medical decisions, claim regulatory compliance, or replace certified monitoring equipment. The paper must distinguish a sensor-modeling exercise from an official air-quality measurement system.
